# at_pheno

拟南芥（*Arabidopsis thaliana*）自然生态型（千量级个体）× 全基因组高密度标记（10⁶–10⁷ 量级，物联）的表型预测研究。

四个可证伪假设：

1. **H₁** 标记密度响应是性状依赖的——不同性状在不同密度处饱和，不存在全局最优密度。
2. **H₂** 在控制同一批标记、同一参数量、同一训练过程之后，保留真实染色体边界／物理位置／局部连续性的模型，只有对拆散对照仍占优时，才被认可为"使用了真实基因组组织信息"。
3. **H₃** 随机同分布 CV 中观察到的增益，若在遗传背景外推时显著衰减，就不能解释为"可迁移的基因型→表型关系"。
4. **H₄** 双向 SSM 模型的作用必须通过参数量与输入匹配的一维对照验证；不以模型名称或双向上下文能力替代实验依据。

**主要预测终点**：具体实验条件下的 accession 级定量表型。若原始研究提供经过实验设计校正的 accession mean / BLUP / 其他标准化表型，则沿用其正式定义并记录来源；不同研究／地点／温度／处理下的同名性状原则上视为不同终点，缺乏明确 harmonization 协议时不合并。
