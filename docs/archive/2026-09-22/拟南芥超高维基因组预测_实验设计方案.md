# 拟南芥超高维基因组预测实验设计方案

## 1. 研究目标与假设

本研究拟在 *Arabidopsis thaliana* 自然生态型中系统检验全基因组高密度变异的预测信息增益，并进一步判断这种增益是否依赖真实基因组组织以及能否在群体分布变化时保持。研究对象不是“能否将 Mamba 运行到千万级 SNP”，而是三个相互关联但必须分别验证的问题：第一，在样本数约为千量级而标记数可达百万至千万量级的条件下，增加标记密度是否在严格独立的测试个体中带来稳定的表型预测增益；第二，在控制输入标记、模型容量和训练过程后，染色体边界、物理位置与局部连续性等基因组组织是否提供独立于标记数量的预测信息；第三，随机同分布划分中观察到的增益是否能够迁移到遗传背景不同的自然群体。现有证据已经表明，拟南芥基因组预测的模型排序明显依赖性状遗传架构和群体结构，因此本研究不设定“复杂模型应普遍优于线性模型”或“全密度变异应普遍优于 LD 降维标记”的方向性前提[6–8]。

将性状 \(t\) 在标记密度 \(D\)、群体分布条件 \(S\) 和模型 \(M\) 下的泛化表现记为

\[
P_{t}=f(D,A_t,S,M),
\]

其中 \(A_t\) 表示性状的遗传架构。主分析围绕四项可证伪假设展开。其一，marker-density response 具有性状依赖性，不同性状的预测表现可能在不同标记密度处达到饱和；其二，在相同标记集合下，保留染色体内真实顺序和物理距离的模型只有在严格的结构破坏对照中仍保持优势，才可认为利用了真实 genomic organization；其三，随机交叉验证中的模型增益若在遗传群体外推时显著衰减，则不能解释为可迁移的 genotype-to-phenotype relationship；其四，bidirectional state-space modeling 的作用必须通过参数量和输入表征匹配的单向对照验证，不以模型名称或理论上的双向上下文能力替代实验依据。

研究的主要预测终点为具体实验条件下的 accession-level quantitative phenotype，而不是未经定义的“育种值”。若原始研究提供经过实验设计校正的 accession mean、BLUP 或其他标准化表型，则沿用其正式表型定义并记录来源；不同研究、地点、温度或处理条件下的同名性状原则上视为不同预测终点，不在缺乏明确 harmonization protocol 的情况下合并。

## 2. 数据体系与预分析设计

主基因型采用 1001 Genomes Project release v3.1 的 1,135 个自然生态型。该资源以 TAIR10 为参考组装，在核基因组中报告 10,707,430 个二等位 SNP 和 1,424,879 个小型 indel[1]。本研究第一阶段仅分析核基因组二等位 SNP；indel、结构变异和泛基因组差异不与 SNP 主实验同时引入，以免把 variant type 与 marker density 的效应混合。原始 10,707,430 是资源层面的上限，而不是任一表型或任一交叉验证折中的实际模型输入数。正式分析必须逐折记录经过样本交集、训练集单态位点排除和缺失控制后实际保留的 marker 数。

表型来自 AraPheno/AraGWAS 及其对应原始研究[2,3]。每个表型首先进行独立的数据审计，建立 accession identifier、表型来源、实验条件、单位、重复测量规则、缺失模式和 1001 Genomes 样本交集。若一个 accession 在同一表型中存在技术或生物学重复，优先采用原始研究正式发布的 summary phenotype；只有原始资源未给出汇总值且重复测量具有相同实验条件时，才按照预先冻结的规则重新汇总。任何表型变换均在模型训练之前明确定义。深度模型若需要数值稳定化，仅在 outer-training 中估计均值和标准差，并在计算 RMSE/MAE 前将预测值恢复到原始表型尺度。

正式研究分为 broad trait panel 与 core trait panel 两层。broad panel 纳入所有同时满足数据来源明确、与 1001 Genomes 匹配关系可核验且有效样本量达到预先规定下限的连续表型，用于 GBLUP/RKHS 等低成本模型的 marker-density response 分析；它的目的在于避免仅依据少量易预测性状推断一般规律。core panel 从 broad panel 中按表型本体类别和样本量预先选择 6–8 个性状，覆盖至少 phenology/development、morphology/whole-plant traits 与 biochemical/ionomic traits，并尽量来自不同原始实验。选择依据限定为表型类别、样本量、数据完整性和原始研究信息，不使用本研究任何候选模型的预测性能。高度相关的同源表型，例如同一研究中不同温度下的 flowering time，可同时报告，但在跨性状归纳中不得视为完全独立的生物学重复。

性状进入 confirmatory core analysis 前进行可估计性审查。随机划分分析原则上要求 \(n\ge 300\)；population-shift analysis 不采用单一固定样本量阈值，而在冻结分组后报告各测试群体的实际 \(n\) 及其可达到的相关系数置信区间宽度。样本过少而导致效应估计高度不稳定的群体只作探索性报告，不参与跨群体主结论。表型类别与遗传架构的关系以外部文献和训练集内部的描述性统计为依据；本研究可以在 outer-training 中估计 SNP heritability、主成分相关性和 GWAS signal concentration 以辅助解释，但这些指标不用于事后挑选“适合”候选模型的正式性状。

RegMap 及其插补资源仅作为补充验证。RegMap 的 1,307 个 accessions 中有 413 个同时属于 1001 Genomes，Arouisse 等以 1,135 个 1001G accessions 为参考对其余样本插补后得到 2,029 accessions、约 300 万高质量 SNP[4]。因此，它不能被描述为与 1001G 完全独立的测序队列；若存在足够表型，RegMap-only accessions 可作为 supplementary transport test，但必须明确其基因型由 1001G reference panel 插补这一依赖关系。

基因型统一采用 `(chromosome, position, REF, ALT)` 标识，并保持 release 中的 ALT allele orientation。深度模型默认输入为 ALT dosage 与 missing indicator；不在不同训练折内根据 minor allele 重新翻转编码，以避免同一位点在不同折中改变语义。拟南芥自然生态型高度纯合，但异合 call 的实际比例先从数据中审计，不预设为零。缺失填补值、marker scaling、MAF/MAC 以及任何 data-dependent filtering 均只由 outer-training 估计并应用于对应 outer-test。

为了把“标记数量”与“低频变异组成”分开，定义三个基因型全集。`COMMON` 为 outer-training 中 call rate≥0.95 且 MAF≥0.05 的常见变异；`MAC5` 在相同 call-rate 要求下保留 MAC≥5 的位点；`RELEASE-VARIABLE` 仅排除 outer-training 中单态或 call rate<0.95 的二等位 SNP，不施加进一步的频率阈值。1001 Genomes 对 SNP calls 的总体准确度较高，但原论文同时指出估计错误主要集中于 singleton variants[1]，因此 `RELEASE-VARIABLE` 只作为接近 release-level 10.7M 输入的探索性上限，不作为主要生物学结论的唯一依据。COMMON 用于主 marker-density curve，以避免随着密度增加同时改变 allele-frequency spectrum；COMMON→MAC5 用于正式检验低频变异是否提供附加信息，MAC5→RELEASE-VARIABLE 则作为 singleton/ultra-rare variant 的敏感性分析。不同 outer fold 的实际 marker 数必须分别报告。

## 3. 实验设计与模型比较

marker-density response 是先于复杂模型比较的第一项正式实验。对每个 outer-training partition 的 COMMON marker universe 构建 \(10\mathrm{K}\)、\(50\mathrm{K}\)、\(250\mathrm{K}\)、\(1\mathrm{M}\) 和 `ALL-COMMON` 五级密度。稀疏层级通过仅依赖 marker identity 的确定性 hash 排序建立嵌套子集，使 \(10\mathrm{K}\subset50\mathrm{K}\subset250\mathrm{K}\subset1\mathrm{M}\)，并按染色体 marker 数比例分配，以避免人为偏向某一染色体。统计基线阶段另外生成若干独立 hash salt 的密度梯度，用于估计“具体抽到哪些 SNP”造成的 subset-selection variance；正式深度模型使用预先冻结的一套 canonical ladder，并在关键结果上用第二套 ladder 进行敏感性复核。与之并行，在 outer-training 内进行 LD pruning，采用预先固定的 \(r^2\) 阈值系列并报告各阈值实际剩余 marker 数。前者回答“增加位点数量是否有增益”，后者回答“保留更多高度相关位点是否仍提供信息”，两类结果不合并解释。

广义线性基线至少包括 GBLUP 和一个显式 marker-effect shrinkage model。GBLUP 是主数量遗传基线；Ridge/rrBLUP 与 GBLUP 在特定编码和方差设定下具有紧密的 primal–dual 联系，因此不把二者的微小实现差异当作独立生物学证据。Elastic Net 或 Bayesian variable-selection model 用于检验效应更稀疏的性状；Gaussian/RKHS genomic kernel 作为不依赖局部顺序的非线性相似度基线。另设一个仅使用训练集基因型主成分的 `PC-only` 回归模型，其目的不是参与“最佳模型”竞争，而是定量显示 population structure 本身能够解释多少随机 CV 表型信号。对于 core panel，再增加 five-chromosome multi-kernel GBLUP，使每条染色体具有独立 kernel/variance component，以检验简单线性模型利用 chromosome-level structure 后能达到的水平。只有当候选深度模型超过这些结构化统计基线，才有必要把优势归因于更复杂的 sequence representation。

候选主模型采用 chromosome-aware hierarchical state-space representation。原始 BiMSGP 将 \(B\times M\times2d\) 双向表示直接 flatten 后进入全连接 decoder；其接收稿在 33,709 markers 的 Wheat2000 上已达到约 1.105 billion parameters，说明 Mamba 主干的线性扫描复杂度并不能保证整个模型对千万级 marker 可扩展[11]。本研究因此不直接延伸该 decoder，而要求预测头参数量与原始 marker 数 \(M\) 解耦。每条染色体独立按 TAIR10 physical position 排序，先由共享 local encoder 在固定物理窗口内将全部 marker 压缩为低维 token，再由 chromosome-level SSM 建模窗口间依赖；五条染色体分别编码和池化，最终由固定维度的 phenotype head 完成回归。主配置采用固定 physical windows，是因为其定义与表型无关、跨 outer folds 稳定并能显式保留距离；窗口尺度在方法开发阶段冻结，正式 core traits 不再根据测试结果修改。5、10、25 kb 等不同尺度仅作为预先规定的敏感性分析，不把任一尺度解释为普适 LD block。

local encoder 必须真正读取窗口内全部 eligible markers，而不能先通过表型相关筛选把千万级输入隐式降为少数位点。每个 SNP 的基本信息包括 genotype state、missingness 和相对物理位置；每个窗口输出固定维度 token。chromosome-level SSM 在染色体边界处显式终止状态传播，并使用 absolute/relative position 或 \(\log(1+\Delta bp)\) 描述非等距物理位置。该设计的计算目标是使主干计算近似为 \(O(M)+O(T)\)，其中 \(T\ll M\) 为 genomic-window token 数，而 trainable parameter count 不再随 \(M\) 成比例增加。模型是否达到这一目标由实测参数量、显存和 wall-clock scaling 验证，而不是由理论复杂度宣称。这里的“全密度”仅指某一预先定义 variant universe 中全部 eligible markers 均进入模型，不把未经频率与训练集可估计性约束的 10.7M 原始计数等同于统计上合理的正式输入。

近期方法比较分为“输入信息一致的主比较”和“文献方法复现”两类。主比较要求模型读取同一 marker set、同一 outer split 且不使用 test phenotype 派生信息，至少包含 chromosome-aware hierarchical SSM、parameter-matched CNN/local-convolution model、unidirectional SSM 以及一个去除 chromosome/position 结构的 pooled SSM。GPformer 可在其计算可承受的共同 marker density 上作为高效长依赖模型对照[9]。GP-WAITER 由于包含 GWAS-derived SNP weights，属于 phenotype-informed representation，不与纯 genotype models 混为同一信息条件；若纳入，其 GWAS 权重必须在每个 outer-training partition 内重新计算，与原论文 cross-validation 中的处理原则一致[10]。原始 BiMSGP 由于 flatten decoder 的规模约束，仅在其实际可运行的 marker density 上用于直接架构参照；若将 decoder 改为 pooling，则应明确命名为 modified BiMSGP reference，而不能作为原论文实现的等价复现。

真实 genomic organization 的验证采用层次化破坏实验，而不是简单比较网络深度。由于主模型首先在固定 physical windows 内聚合 marker，直接随机打乱所有 SNP 会同时改变窗口组成、局部顺序和物理距离，无法归因。正式消融分别设置：在窗口组成不变时随机打乱窗口内 SNP 顺序，用于检验局部 sequential order；保持窗口内部不变但打乱同一染色体上的 window order，用于检验 chromosome-scale order；保持全部顺序不变而将真实 \(\Delta bp\) 替换为常数步长，用于检验物理距离；比较 chromosome state reset 与跨染色体串联传播，用于检验 chromosome boundary；比较 parameter-matched bidirectional 与 unidirectional SSM，用于检验双向上下文。所有消融使用同一 marker set、tokenizer、outer splits、训练预算和预测头；对于双向/单向比较，通过调整 hidden dimension 或权重共享使总 trainable parameters 处于预先规定的匹配范围，避免把双向模型的额外容量误认为方向性机制。

random-distribution prediction 与 population-shift prediction 使用不同的外层划分。随机主分析采用 5-fold outer CV，并依据 1001 Genomes 已发表的 genetic group labels 进行 genotype-only stratification，使各折尽可能维持群体组成，而不依据表型值人为平衡测试集。population-shift 主分析优先使用 1001 Genomes 的已发表 genetic clusters 做 leave-one-group-out 或 predefined group-held-out evaluation；只有具有足够 phenotype observations 的群体进入正式比较，其余群体只作探索性结果。country/region-held-out 可作为次级分析，因为国家标签与遗传群体并不等价，且同时携带 local-adaptation 与采样历史信息。PCA 后聚类不作为首选主分组；若因具体表型缺失导致已发表 group 无法形成有效测试集，才作为预先说明的敏感性方案，并仅使用 genotype 定义分组。

population structure 另设两个诊断量。在 random CV 中报告 PC-only baseline，并计算 within-group centered performance：对 outer-test accession 的表型和预测值使用 outer-training 中相应 genetic group 的表型均值进行中心化，再评估中心化后的 PCC/RMSE。该指标只用于判断模型是否主要依赖群体间均值差异，不替代原始 phenotype prediction；对于 completely held-out group，由于训练集中不存在该组表型均值，不计算这一指标。


本研究第一阶段不同时引入 environmental covariates、transcriptome、methylome 或 DNA foundation-model-derived variant scores。这些信息源会同时改变可用样本交集和模型输入语义，使 full-density marker effect 与额外组学/预训练信息的贡献难以分离。Caduceus、PlantCaduceus 等 DNA language models 处理连续 A/C/G/T 序列，与 population-level allele-dosage prediction 的输入语义并不相同，因此不作为简单替换 regression head 的直接主基线；若后续研究引入其 variant-effect score，应作为独立的 sequence-prior increment 进行检验。

研究按 broad-to-core 的顺序执行。broad trait panel 首先完成 GBLUP/RKHS/PC-only 的 marker-density response，以确定不同表型类别的饱和模式；随后在预先冻结的 core panel 上运行完整深度模型比较。若 broad panel 显示 COMMON 密度在 250K–1M 已普遍饱和，仍保留预先指定的一个 macroscopic trait 和一个 biochemical/ionomic trait 进行 MAC5 深度模型实验，用于排除“线性模型无法利用高密度信息而结构化模型可以”的可能；只有这两个 sentinel traits 也缺乏稳定增益时，才停止对其余 core traits 的 MAC5 大规模训练；RELEASE-VARIABLE 仅在计算可行且 MAC5 结果提示低频信息可能仍未饱和时进入敏感性分析。sentinel traits 在查看候选模型结果之前按样本量和表型类别确定，避免以结果驱动资源分配。

## 4. 交叉验证、统计推断与计算评价

所有最终模型比较遵循 outer-test isolation。每个性状预先生成并冻结 outer split manifest，所有模型和 marker densities 共用相同 outer-test accessions。outer-test phenotype 在模型训练、feature construction、checkpoint selection、learning-rate adjustment、marker ranking、GWAS weighting 和 architecture selection 中均不可访问。统计模型的 penalty、kernel bandwidth 或 variance-component related hyperparameters 在 outer-training 内通过 inner CV 选择；深度模型的 architecture family、tokenizer 与主要超参数范围先在单独的 method-development trait 上确定并冻结，该性状不进入正式跨性状主结论。core traits 的 inner validation 仅用于预先限定范围内的学习率/正则化选择和 early stopping。最终 outer-test 每次只用于一次性能计算。该设计直接避免 BiMSGP 接收稿中 held-out fold 同时承担 checkpoint、学习率调节和结果报告所造成的 model-selection bias[11,12]。

method-development trait 的选择同样在正式比较前冻结，并与 core confirmatory traits 分离。其作用仅限于确定可运行的 physical-window tokenization、模型维度、优化器范围和显存策略；不得依据其结果挑选 core traits，也不得将该性状的最优结果并入最终平均性能。若 development trait 与某一 core trait 来源相同且表型高度相关，应更换 development trait 或将相关 core trait降为 secondary analysis，避免通过跨性状相关性间接优化正式终点。

深度模型使用三个预先固定的 initialization seeds。主结果不从多个 seeds 中选择最佳值，而分别保存 accession-level predictions，并报告平均效应及 seed sensitivity。随机 outer split 以一个冻结的 5-fold manifest 作为主分析，另以两套独立 genotype-stratified manifests 进行 split sensitivity analysis；这些重复不被当作相互独立的实验重复。population-shift 分析使用固定 group-held-out partitions，不通过反复随机分组扩大样本量。

回归主指标为 Pearson correlation coefficient (PCC)，RMSE 和 MAE 为互补误差指标。对于不同量纲性状，RMSE/MAE 仅在同一性状内部比较；跨性状展示以 PCC 及标准化误差为主。每个 outer fold 都保存原始 \(y\) 与 \(\hat y\)，并在一个完整 outer-CV cycle 中拼接得到每个 accession 恰好一次的 out-of-fold prediction。主模型效应定义为同一 accession 上的配对差异，例如

\[
\Delta_{model,t,D}=PCC(\hat y_{\mathrm{CH\text{-}SSM}},y)-PCC(\hat y_{\mathrm{GBLUP}},y),
\]

\[
\Delta_{density,t}=PCC(\hat y_{ALL-COMMON},y)-PCC(\hat y_{1M},y),
\]

以及群体外推衰减

\[
\Delta_{shift,t,M}=PCC_{random}-PCC_{group-held-out}.
\]

对相关系数差异的主要不确定性估计采用基于同一 OOF accessions 的 paired bootstrap，并在 random CV 中按已发表 genetic groups 分层重采样，以维持总体群体构成。该 bootstrap 反映测试样本抽样的不确定性，但不能完整包含重新抽取训练集并重新拟合模型带来的方差，因此同时报告 alternative split manifests 和 deep-model seed sensitivity。普通 paired \(t\)-test 或 Wilcoxon test 不把交叉验证 folds 当作独立实验重复；若使用 repeated-CV 的形式检验，则必须采用考虑训练集重叠的 corrected resampling 方法，并将其作为敏感性分析而非唯一证据[12,13]。

主要结论以 effect size 和 95% confidence interval 为中心。正式统计比较在实验开始前限定为少量 primary contrasts：ALL-COMMON vs 1M 的 density increment、主模型 vs GBLUP、主模型 vs chromosome multi-kernel GBLUP，以及 ordered vs structure-disrupted 主消融。core traits 内的同类 primary contrasts 采用 Holm procedure 控制 family-wise error；其余大规模超参数、敏感性和 attribution 分析标记为 secondary/exploratory。统计显著性不替代效应大小；若 CI 同时包含对科学结论有意义的正负效应，则结论应表述为证据不足而不是“模型等价”。smallest effect size of interest 不在结果产生后设定，而根据 core traits 样本量、基线不确定性和实际应用尺度在正式训练前登记。

计算可扩展性是与预测表现并列的结果，而不是附带描述。所有可扩展深度模型在同一硬件和软件环境下，以至少 50K、250K、1M、ALL-COMMON、MAC5，以及代表性性状中计算可行的 RELEASE-VARIABLE 输入记录 peak GPU memory、wall-clock time per epoch、time per sample、throughput、trainable parameters、effective token count 和 batch size。若需要 gradient checkpointing、chunking 或 mixed precision，必须作为模型配置固定并报告。不同 marker density 因显存限制采用不同 batch size 时，以单位样本训练时间和吞吐率为主要效率量，不直接比较总 epoch 时间。候选 hierarchical SSM 的最低可扩展性要求是 phenotype head 参数量与 raw marker count 无关，且 MAC5 的 forward/backward 能在预定硬件上实际完成；如果只能通过丢弃大量 marker 才运行，则不能称为 full-density model。

## 5. 生物学解释、结果判定与研究边界

解释性分析只在预测模型及其评估协议冻结之后进行，并与模型选择隔离。Mamba selectivity、attention、Integrated Gradients、SHAP 或 permutation importance 均只回答模型输出对输入变化的敏感性，不直接表示 causal effect。正式解释首先评估跨 outer folds 和 initialization seeds 的 attribution stability，再把稳定区域与独立的 AraGWAS、TAIR/Araport、FLOR-ID 或 pathway annotation 对照。若某比较模型在训练中已经使用同一性状的 GWAS-derived weights，例如 GP-WAITER，则其与该 GWAS 结果的重叠不能再作为独立生物学验证；此类模型的解释应改用独立研究、功能注释或未用于构造权重的证据来源。

SNP-to-gene mapping 不采用固定 ±1 Mb 作为默认范围。主分析使用基于物理距离且与拟南芥局部 LD 尺度相符的多个窗口进行敏感性比较，或在数据允许时依据局部 LD/recombination structure 定义候选区域。富集分析的 null regions 应尽量匹配 chromosome、MAF、local marker density、gene density 和 LD characteristics，避免仅凭全基因组超几何检验把高 SNP 密度区域误判为功能富集。已知开花调控基因如 FRI、FLC、FT、CO、GI 可以作为预先定义的 positive-reference set，但召回这些基因只表示模型 attribution 与已知生物学一致；未召回也不能据此否定基因功能。

各主要假设采用预先定义的证据边界。marker-density information gain 只有在相同 accessions、相同 outer splits 与相同 allele-frequency universe 下，较高密度模型在独立 OOF predictions 中出现稳定正向效应时成立；若 250K 或 1M 已达到饱和，则研究结果应表述为 density saturation，而不是以计算规模作为性能贡献。真实 genomic organization 只有在 local-order、window-order、distance 或 chromosome-boundary 的单因素破坏中出现可重复损失时才获得支持；若 ordered 与 disrupted controls 基本一致，则停止“模型利用真实基因组拓扑”的机制性表述。bidirectionality 同理，只有 parameter-matched comparison 支持时才视为有效归纳偏置。

population-shift 结果按预测任务本身解释。若复杂模型相对 GBLUP 的优势在 random CV 和 group-held-out 中均保留，可以认为其 representation 在当前群体划分下具有更好的迁移证据；若优势只存在于 random CV，而 PC-only baseline 同时表现较强或 within-group centered performance 明显下降，则更合理的解释是模型更充分利用了 population-specific ancestry/LD signals。若所有模型在 group-held-out 中均显著衰减，则结果主要揭示自然群体 genotype-to-phenotype mapping 的 transportability boundary，而不能简单归因于某一模型失败。

本研究不以预测相关性证明 biological epistasis，也不把 Mamba state、attention 或 feature attribution 解释为 causal locus。全密度输入若优于 LD-reduced input，只能说明在当前样本、性状和模型条件下额外变异携带可利用的预测信息；它不能证明这些 marker 本身均具有功能作用。相反，full-density 无增益、penalized regression 保持最强竞争力、真实顺序消融无效或模型优势仅限于少数 biochemical traits，均属于能够直接回答研究问题的有效结果。

## 6. 数据记录、可复现性与参考文献

所有正式结果均以 accession-level prediction 为基本记录单位。每个表型保存 accession mapping、原始实验来源和有效样本表；每个 outer split 保存训练/测试 accession IDs；每个 marker density 和 outer fold 保存实际 `(chromosome, position, REF, ALT)` marker manifest 以及训练集计算得到的 call rate、MAF/MAC、LD filtering 和 imputation/scaling 参数；每次模型拟合保存完整配置、参数量、seed、训练曲线、checkpoint/epoch selection 信息、运行时间和显存峰值。论文中的 PCC、RMSE、MAE、confidence interval、density curve 和 attribution enrichment 均从这些冻结的原始记录重新计算，不以手工整理后的均值表作为唯一数据来源。基因型 release、TAIR10 annotation、AraPheno/AraGWAS snapshot 和分析代码均记录版本及校验值，以保证后续能够重建相同的 sample × marker × phenotype intersection。

正文结果建议围绕五类证据组织，而不重复绘制同一组均值：broad trait panel 的 density-response trajectories；core traits 中主模型相对统计/近期方法的 paired effect estimates；genomic-organization 的结构破坏消融；random 与 group-held-out 的 transportability comparison；以及预测成立性状中的 attribution stability、独立功能注释和计算 scaling。所有模型排名均按具体性状和评估条件表述，不给出跨性状“总体最优模型”结论。
