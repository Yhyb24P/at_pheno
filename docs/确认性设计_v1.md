## 确认性问题

在相同 additive genomic prediction 框架下，比较训练折内 COMMON marker universe 的 `COMMON_250K` 与 `COMMON_ALL`。

- Primary trait：DTF1 (703)
- 主评估：near-clone-safe / published-group-balanced 5-fold outer CV
- Primary endpoint：`ΔQ²_trainmean`
- primary contrast：`COMMON_ALL − COMMON_250K`
- SESOI：`+0.01 ΔQ²`

SESOI 是项目预先规定的 practical margin：相对于每个外层训练折的 train-mean baseline，多解释一个百分点的平方误差尺度；它不是文献共识声明。只有 `LCB95(ΔQ²)>0.01` 才称 practical importance；`LCB95>0` 且点估计至少 0.01 只能称正效应、点估计超过 SESOI。748 依同一规则作独立复现。IID、published ADMIXTURE LOGO、RL/CL、全 density ladder、alternate salts 与 near-clone cutoff 作为次级或敏感性分析。

## Near-clone block 的精确化

`at_pheno_nearclone_v1` 以只依赖 chromosome、position、salt 的 250K HDF5 binary-state coordinate panel 作为候选筛查。直接在 250K 面板上以 `d≤0.001` 建连通分量曾产生一个 13-member 稀疏链；其全 HDF5 复核显示若干临界边是子样本误分类，而非真实完整二态基因组边。

因此 canonical block 定义为：先以同一 250K 面板的已登记敏感性阈值 `d≤0.002` 提名候选对，再在全部 10,709,949 个完整 HDF5 binary states 上精确计算这些 screened candidate pairs 的 Hamming distance，并以原冻结主阈值 `d≤0.001` 定边、以 connected components 定 block。该修正没有改变主阈值、没有使用 REF/ALT 语义或表型数据；它只避免有限 marker panel 在临界处的判边噪声。

候选筛查得到 2,686 对。全 HDF5 精确结果为 11 条主边、4 个多成员 block、最大 block 8、最大 block edge density 0.2857；故未触发 chain blocker。基于 hash 抽样的 Bernoulli 近似，真实 `d=0.001` 的 pair 被 `d≤0.002` screen 漏掉的 family-wise 上界为 `6.5×10⁻³⁷`；此为保守模型界，而非经验频率。四个正式 phenotype cohort 均未包含这些多成员 block 的任一 accession，因此当前 blocked split 的实质是 near-clone-safe/group-balanced，而不是已观测到的 relatedness-shift 测试。
