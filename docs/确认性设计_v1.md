## 确认性问题

在相同 additive genomic prediction 框架下，比较训练折内 COMMON marker universe 的 `COMMON_250K` 与 `COMMON_ALL`。

- Primary trait：DTF1 (703)
- 主评估：near-clone-blocked 5-fold outer CV
- Primary endpoint：`ΔQ²_trainmean`
- primary contrast：`COMMON_250K − COMMON_ALL`（报告方向固定为 ALL 减 250K）
- SESOI：`+0.01 ΔQ²`

SESOI 是项目预先规定的 practical margin：相对于每个外层训练折的 train-mean baseline，多解释一个百分点的平方误差尺度；它不是文献共识声明。748 依同一规则作独立复现。IID、published ADMIXTURE LOGO、RL/CL、全 density ladder、alternate salts 与 near-clone cutoff 作为次级或敏感性分析。
