# 拟南芥超高维基因组预测实验设计 v0.1

更新：2026-09-22。状态：**待真实数据审计后冻结的工作协议**。性状清单、近亲阈值、预算和最小有意义效应尚未冻结，不能称为已预注册。可运行代码仅覆盖明确标注的 pilot。

## 1. 目标与假设

统计单位为 accession；预测具体研究、环境及汇总规则下的连续表型。第一阶段仅用核二等位 SNP，不引入额外环境、多组学或预训练分数。自然生态型表型预测不直接称为育种值预测。

- H1：固定 COMMON 全集与抽样规则，额外标记的预测收益是否因性状而异？
- H2：控制 marker/token 输入后，结构编码是否优于简单模型，并能通过预定义结构干预？
- H3：H1/H2 的收益在近亲分块及群体外推中是否保留？
- H4：区分频率核、载体支持和模型权重后，低频变异是否仍有增量？

双向 SSM 是 H2 的组件实验，不预设为研究中心。收益指当前任务和样本条件下的预测信息，不指 SNP 因果作用。两个性状无收益不能排除其他性状收益。

## 2. 数据与性状审计

主资源拟为 [1001 Genomes v3.1](https://1001genomes.org/data/GMI-MPI/releases/v3.1/)。分别登记原始调用 VCF 与预插补 HDF5 的 release、URL、下载时间、字节数、SHA256、组装、坐标、样本及编码，不混用两者缺失语义。

严格 inductive 分支尽量从非全样本插补调用构建矩阵，各拟合折独立 QC/填补；上游群体联合 calling 仍是资源依赖，需披露。HDF5 分支须先检查0/1含义、插补参考、样本和位点清单；不能直接当0/1/2，也不能从已插补矩阵重建原始缺失。若插补见过全部基因型，作为明确标注的预处理依赖敏感性分支。

位点主键：TAIR10 chromosome、1-based position、REF、ALT；保留 ALT 方向，不按各折 minor allele 翻转。仅保留核1–5染色体、二等位 A/C/G/T SNP；审计异合、缺失、重复位点、近克隆和可疑样本，不假定全部纯合。

表型来自 [AraPheno](https://arapheno.1001genomes.org/faq/rest/)及原始研究，不把 AraGWAS 汇总统计当标签。trait registry 必填：phenotype DOI/ID、study DOI、环境、单位、原始/summary 类型、重复规则、缺失、基因型交集、各群体 n。跨环境同名性状分别定义。

优先来源明确的实验校正值。若 summary/BLUP 使用全样本亲缘或跨目标拟合，披露派生目标依赖；必要时回到原始重复数据重建训练内校正流程，不能仅凭“BLUP”名称视为独立标签。

先选两个候选：一个 phenology，一个非 phenology；按数据条件和样本量选，不看成绩。FT10/FT16 可作数据入口，但同源相关性状不视为独立复现。broad/core panel 数量待交集审计决定，不预承诺6–8个。

同日审计更新：FT10交集1003、rosetteDM407，暂列pilot候选，仍有重复ID待解决；Mo98/Cd111仅150、M130T666仅207，不能按原稿n≥300规则直接进入core。HDF5实际维度10,709,949×1135已核验，但缺REF/ALT和原始缺失语义，正式ALT输入尚未建立。详见 [文件级数据审计](真实数据准备与候选面板.md)。

## 3. 内外层隔离

先冻结样本及外层 manifest；所有模型共用外层测试样本。

1. outer-training 内创建 inner train/validation。外层为群体外推时，内层优先同类 group holdout；群体太少则明确调整调参任务或使用外部固定参数。
2. 每个 inner-training 重新拟合 call rate、MAF/MAC、eligible universe、LD、填补、缩放、PCA、GWAS、特征选择与标签变换。不能先用整个 outer-training 做好再给 inner CV。
3. 在预设网格选参；checkpoint、scheduler、早停都只见 inner-validation。深度模型从内层得到固定轮数规则后在完整 outer-training 重训，或预先声明保留内部 holdout。
4. 选定后在完整 outer-training 重拟合预处理及模型，outer-test 仅作最终评分。查看外层结果后更改配置则相应结果转探索性。

用全体 genotype-only 信息定义已发表群体/近亲块，是冻结抽样设计的明确例外，不允许因此用全体数据估计预测器 PCA/填补。两种用途分别记账。

## 4. 变异全集和密度

COMMON：训练 call rate≥0.95、MAF≥0.05、非单态。MAC5：call rate≥0.95、MAC≥5、非单态。RELEASE-VARIABLE：同缺失阈值，仅去训练单态。MAC按未缺失二倍体 allele copies 计算，同时报 minor-carrier accession 数与测试携带者；测试频率只作冻结后的描述。

COMMON 内按 SHA256(salt, variant key) 排序取前10K、50K、250K、1M、ALL，严格嵌套。当前代码采用全局哈希，染色体比例是期望近似而非精确配额；需报告各层频谱与覆盖。正式预设三套 salt，冻结 canonical salt。LD pruning 单独冻结阈值/窗口/步长且仅训练拟合，不与 hash 密度混为一种实验。

某折少于请求密度则该层不可用，不冒充达到密度。ALL与1M若相同，不形成 contrast。内层较小时可使用预设“最多K”规则，但记录 capped 标志；正式对比优先共同可达密度。

COMMON→MAC5 不称纯 rare effect。另建分别归一化的 K_common 和 K_rare（MAC5中不属COMMON者），在训练内优化权重；补充相近标记数/预算对照，讨论数量、频谱、收缩的共同变化。

## 5. 划分任务与结构诊断

| 任务 | 划分 | 含义 |
| --- | --- | --- |
| IID pilot | accession 随机 K-fold | 当前分布插值；不隔离近亲 |
| 近亲分块 | genotype 定义近克隆/强亲缘连通块整块分折，尽量平衡已发表群体 | 去近重复后的泛化 |
| 群体外推 | 已发表遗传群体 LOGO 或预定义组合留出 | 未见背景预测 |
| 地理外推（次级） | 国家/地区留出 | 地理与采样环境联合变化 |

近亲阈值按基因型审计冻结，报告最大块及跨组块；避免连通链合并多数样本后仍勉强 K-fold。遗传群体边界不是近亲边界。各测试组报告 n、表型方差、频率差和近亲距离；恒定/极小样本 PCC 保留 NA。

诊断：训练均值；PC-only（训练内PCA与回归，PC数内层选）；随机/分块中的训练 group-mean predictor，未见组回退全训练均值并标注；各组 PCC/RMSE。

描述性 within-group PCC 对各组 OOF 的 y 与 prediction **分别**减各自组均值再拼接求相关；测试标签仅用于评分，不影响预测。这不是可部署校正器。对 y 与 prediction 减同一个 c_g，RMSE/MAE严格不变，不能作为去结构证据。

随机与外推性能差只描述任务，不解释为纯 shift 因果效应；二者训练量、测试组成和方差不同。比较各任务内“候选−同基线”的配对增益，必要时补训练量匹配敏感性。

## 6. 基线、表示与新方法

已实现：训练均值与 additive kernel ridge。训练均值填补并中心化 dosage 得 Z，p为训练ALT频率：

`K = ZZᵀ / Σ 2p_j(1−p_j)`

`ŷ = μ_train + K_test,train (K_train + λI)⁻¹(y_train−μ_train)`

这是明确核定义的 GBLUP 类正则化预测，不是 REML 方差分量估计。自交群体使用此归一化不声称真实HWE；另种缩放对应不同先验，须单列敏感性。内层最小 MSE 选λ，最终同时报告相关和误差。

正式基线待实现：PC-only、sparse regression、RKHS、染色体多核和频率多核。缺失这些基线时不宣布新模型胜出。每类搜索预算及失败完整保存。

候选结构模型不沿用 BiMSGP flatten head。以10kb固定窗口为pilot（5/25kb敏感性），保留位点身份、REF/ALT、相对位置、染色体；共享local encoder形成token，再作染色体内建模和固定维pooling/head。空窗口、mask与坐标定义冻结。

先做表示充分性检查：真实基因型上模拟已知单SNP、稀疏加性、多基因和预定义交互，比较全marker additive与token线性/MLP。模拟只检查压缩/优化，不证明真实性状架构；若强单SNP信号都丢失，先修tokenizer。

同token对照至少线性/MLP/CNN与单向/双向SSM，head一致；参数量目标±5%，同时报告实测时间，不能把参数匹配等同算力匹配。深度模型若额外使用missing indicator，补missingness-only与同信息对照，避免把批次/缺失提示当遗传增益。

## 7. 结构干预

置乱先于训练、重新训练模型；固定映射用于所有accession及train/test，不逐个样本独立置乱，不以inference-only scramble为主证据。

| 干预 | 保留/改变 | 可解释范围 |
| --- | --- | --- |
| 窗口内置乱 | 成员与位点-坐标配对保留，改变扫描邻接 | 顺序归纳偏置；坐标仍在 |
| 窗口间置乱 | 窗口内部及染色体归属保留 | 长程扫描顺序；保留绝对位置时仍可定位 |
| 去坐标通道 | 保留身份、dosage、顺序、成员 | 显式bp信息贡献；身份可能隐含位置 |
| 窗口内Δbp置常数 | 成员与顺序保留 | 非等距局部间隔；不使用本已等距的窗口中心冒充干预 |
| state reset开关 | 同一拼接序列与readout，仅改变边界状态/卷积历史 | 染色体边界传播，不能同时改变pooling |
| 单向/双向 | tokenizer/head/预算一致 | 方向性收益，不是上位性证据 |

set encoder若本身置换不变，窗口内置乱是软件不变性检查。全基因组shuffle同时改变窗口归属属于复合干预，仅次级解释。

## 8. 评分与推断

每accession每outer cycle保存一次原尺度OOF、fold、trait、model、density、seed、marker_count、train_mean。每seed分别评分；先平均预测后评分是ensemble，单独命名。重复split不扩大独立生物学样本量。

共同报告PCC、RMSE、MAE、`Q²_trainmean=1−Σ(y−ŷ)²/Σ(y−μ_train,fold)²`。组外推优先逐组结果；pooled OOF PCC可能由组间差异驱动，只作总体描述。恒定预测或标签使PCC未定义时保留NA。

预备primary contrasts：COMMON 250K→ALL（必须不同；数据允许时冻结为1M→ALL）；候选vs additive及同token CNN；一个明确结构干预。性状审计后冻结各contrast、SESOI、多重比较family，不无限两两检验。

配对重采样保持同accession全部模型预测同行；近亲存在时按块、必要时组内分层。固定OOF bootstrap区间明确为“给定拟合结果”的条件性区间，不含完整训练/选择方差。少数组不足以稳定cluster bootstrap时逐组报告并限制主张。

普通fold-wise t/Wilcoxon不作主要确认性证据。修正重复CV检验需论证其假设；Holm仅用于有合理校准的检验，不能修复依赖或把CI跨零直接当p值。SESOI在结果前定义；CI宽则证据不足，完整进入等效带才讨论实用等效。

## 9. 计算规模与阶段验收

本机初始化检测：RTX5090D，32607MiB显存；约93GiB内存、358G可用盘。这不是资源预留，也未验证Mamba CUDA兼容性。

1135×10,707,430 float32 dosage单份约48.6GB（十进制）；uint8约12.2GB，元数据与缺失另计。B=4、M=10,707,430、d=32的FP16 embedding单张量约2.74GB，反向和优化器显著增加占用。分块GRM工作内存O(n²+nB)，运算仍O(n²M)，内层多次重建须实测。

G0：版本/编码/映射审计通过。G1：两性状基础流程可重建OOF、隔离测试、计算可接受。G2：表示模拟、共同输入基线、全密度forward/backward峰值通过。G3：冻结性状、划分、比较和预算后扩展。

sentinel无收益可作为预算停止规则，不能据此排除其余性状有效性。OOM、训练失败、NA、无可比密度都保留。
