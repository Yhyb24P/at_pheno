# 确认性设计 v1.1

这是 G0.1 在任何真实性状预测之前作出的补充冻结；它继承并不修改 [确认性设计 v1](确认性设计_v1.md)。精确 hash 绑定见 `data/manifests/confirmatory_v1_1/freeze_amendment_manifest.json`。

## 已修订的推断口径

- 仅当 `LCB95[ΔQ²(COMMON_ALL − COMMON_250K)] > 0.01` 时，才可称 practical meaningful benefit。
- `LCB95>0` 且点估计 `ΔQ²≥0.01` 只能称为正效应且点估计超过 SESOI，不能称 practical importance。
- additive KRR 的核、缺失处理、alpha 选择、边界扩展、Cholesky/jitter 和失败策略由 `baseline_spec_v1.json` 固定。

## 密度范围与不可用性

237 个冻结训练分区的仅基因型审计均不支持 `COMMON_1M`。该密度在 G1 中预声明为 `UNAVAILABLE`：不拟合、不静默截断、不作为密度梯的一项实际结果。

因此 primary contrast 实际检验的是：训练折内高质量 COMMON SNP 从 250K 增加到 fold-specific `COMMON_ALL`（DTF1 blocked 约 0.39–0.44M）后是否仍有预测收益。它不能被表述为 10.7M 全基因组或 rare-variant 密度优势的检验；后者需独立的 MAC5/release-variable 分支。

## 划分与 near-clone 解释

精确 near-clone 图有四个多成员 block，但四个正式 phenotype cohort 都不包含这些 accession。因而 primary CV 正确名称为 near-clone-safe / published-group-balanced；它不是 relatedness-shift 泛化评估。full-HDF5 距离仅对 250K screen 提名的 pair 作 exact refinement，并非 exhaustive all-pairs。
