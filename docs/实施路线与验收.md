# 实施路线与验收

## 当前完成

原稿原样归档；重点文献/方法审计；v0.1协议；固定BiMSGP参考仓库；Python独立环境与锁文件；严格嵌套QC的CPU additive kernel pilot；测试与双协议合成运行；官方HDF5下载和样本核验、ADMIXTURE标签、七项表型快照及真实交集。最新数据状态见 [候选面板审计](真实数据准备与候选面板.md)。

## 下一阶段：先形成可用数据表

1. 确认使用原始调用还是预插补矩阵，核验准确来源及转换语义；先小区域/小样本试导入再全量处理。
2. 官方1135样本及已发表group的ID核对已完成；继续检查同名异样本、近克隆和批次。
3. 从已下载目录选非phenology候选，下载原始值及study记录；结合原论文冻结重复汇总和单位；逐trait统计真实交集。
4. 决定development traits与confirmatory panel，记录高度相关的同源性状；冻结可行群体和近亲分块。

验收：数据来源、坐标、编码、样本匹配均有证据；有真实交集和群体n，而非只引用数据库总量。未完成这一步不进入正式模型比较。

## 第二阶段：基准与预算

补PC-only、sparse、RKHS；两候选性状先跑10K/50K/250K/ALL；比较OOF、缺失模式、训练均值与群体均值；实测QC/GRM构建和嵌套调参时间。扩大到1M/ALL前预测完整预算，并记录实际marker数。

验收：所有训练选择只依赖训练分区；同一split可复建；小规模与分块数值一致；负对照/已知信号模拟合理。预算不足时缩小探索矩阵，不放松外层隔离。

## 第三阶段：表示与模型

先确定位点身份保留策略及token碰撞风险，再实现固定head的token基线、CNN与SSM。检查正负对照、置乱语义、窗口长度、空窗口、state reset以及全密度峰值。BiMSGP保持参考副本，本项目修改另起明确模型名与来源记录。

验收：全eligible markers实际进入编码；单SNP信号模拟可恢复；同token简单模型齐全；真实GPU完成forward/backward；不能只用主干复杂度公式宣称可扩展。

## 正式运行前必须填写

trait清单与来源、development排除规则、inner/outer manifests、近亲阈值、密度/salt、信息条件、primary contrasts、SESOI、种子及重复划分、调参预算、停止规则、统计区间的抽样单位。相关字段留空时只能标记exploratory/pilot。

不预先承诺论文阳性结果或“首次”。收获可以是饱和曲线、外推边界或表示失效机制，只要对应比较可识别且证据精度合格。
