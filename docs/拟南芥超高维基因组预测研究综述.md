# 拟南芥超高维基因组预测：标记分辨率、表征与跨群体泛化

2026-09-22 重启工作稿。原稿完整归档于 `archive/2026-09-22/`。本文是聚焦研究决策的叙述性综述，不是穷尽检索的系统综述。来源及核验边界见 [文献证据表](文献证据表.md)。

## 摘要

拟南芥自然群体为研究样本数远小于遗传标记数的表型预测提供了资源，但资源总规模不能替代具体性状的有效样本量。已有研究显示，模型表现随性状、群体构成和评估方式变化；更高的标记密度或模型容量没有普遍优势。新的研究应分开考察同一常见变异全集内增加标记数的收益、引入低频变异的条件性收益，以及保留位点身份和基因组结构的表征是否改善预测。群体内插值、近亲分块预测和未见群体预测是不同任务。结构化长序列模型具有工程和方法研究价值，但读取全部位点不等于保留其信息，预测增益也不等于发现上位性。本项目因而以高密度信息增益及泛化边界为主线，将层次化 SSM 作为有条件的模型扩展。

## 1. 资源规模与可预测问题

1001 Genomes 的1135自然生态型和千万量级变异构成研究入口。分析必须区分核 SNP、indel、细胞器位点、原始调用与插补矩阵。官方 v3.1 同时发布变异 VCF、含参考调用文件和预插补 HDF5；这些表示具有不同的数据依赖和缺失语义，不能只因属于同一 release 就互换。[官方资源](https://1001genomes.org/data/GMI-MPI/releases/v3.1/)

统计单位是 accession，而非 VCF 列数、表型行数或实验重复数。AraPheno 支持重复测量，每项表型都需要核验条件、单位、重复编号、汇总方法和 accession 映射。跨温度或跨研究的同名性状原则上分别定义；目标为具体实验条件下的表型，不自动解释为育种值。[AraPheno FAQ](https://arapheno.1001genomes.org/faq/content/)

RegMap/1001G 整合资源的样本重叠与插补参考依赖，使其不能未经去重就充当独立测序队列。使用全体未标记基因型做插补或 PCA 不自动等于表型泄漏，但会改变部署假设：模型可接触目标群体的基因型。这类 transductive 场景需要标注，不能与全部预处理仅见训练样本的 inductive 场景混同。

## 2. 强基线与既有预测证据

本项目同日实际数据核验已显示上述边界的重要性：官方预插补HDF5为1135×10,709,949，但FT10实际交集1003、rosetteDM407；当前AraPheno的Mo98/Cd111交集各150，M130T666交集207。它们的数据库原始行数明显更大。这些是当前资源快照的审计事实，不是文献全部数据资源的上限；详见 [候选面板审计](真实数据准备与候选面板.md)。

Gibbs 等对36个拟南芥性状的比较联系了性状架构、群体结构与模型选择，惩罚回归和非线性方法的优势随性状变化。“不同性状需要不同模型”和“标记筛选影响预测”已是明确前驱，本项目需要通过密度、频谱和外推的分解提供增量。[Gibbs et al., 2025](https://academic.oup.com/genetics/article/229/3/iyaf003/7954791)

Kelly 与 McLaughlin 的四性状 nested CV 比较支持复杂模型可能有增益，但不支持把表达能力直接当作生物学上位性证据。小样本中的灵活模型是否可估计，仍须由外层预测验证。[Kelly & McLaughlin, 2024](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0308962)

公平基线应包括训练均值、PC-only、核和截距定义清楚的 GBLUP 类模型、稀疏回归及无顺序非线性核。Ridge/rrBLUP 与 GBLUP 的对应依赖编码、缩放、截距和方差参数；将等价实现当作独立证据会夸大比较广度。染色体多核和分频率多核可以检验较简单的结构化统计模型能否解释候选模型的收益。

群体结构是可预测信息的一部分，但价值取决于部署人群。ionome 研究显示，总体预测与国家内预测不同，国家留出更困难。高随机 CV 相关不能保证外推；外推下降也不能单独证明原随机结果虚假。[Raimondi et al., 2024](https://www.nature.com/articles/s41598-024-63855-6)

## 3. 密度、频率与表示不是同一个变量

从 COMMON 全集中嵌套抽取10K、50K、250K、1M和ALL，可估计固定抽样规则下增加可用标记的收益。但局部 LD、基因覆盖与 MAF 分布仍可能波动；需要预设重复子集并报告组成。均匀哈希、物理间距抽样与 LD pruning 回答不同问题，应分开解释。

加入 rare variants 时，不只信息量变化，关系矩阵权重、正则化及少数载体影响也会变化。MAC 统计 allele copies；高度自交群体中 MAC=5 并不等于五个独立携带者。低频信息需要通过 common/rare 分量、载体数和测试覆盖解释；训练内极少数载体的效应不一定可验证。

binGO-GS 已结合 GO、GWAS 与组合优化进行子集选择。这类模型使用表型派生信息，不应和纯 genotype 表征混为同一信息条件；特征筛选、组合搜索及最终性能评价必须层级隔离。[Ba et al., 2025](https://www.frontiersin.org/journals/bioinformatics/articles/10.3389/fbinf.2025.1607119/full)

## 4. 长序列方法的价值与限制

课题组的 BiMSGP 已开源。本次检查固定提交 `71084c8fa5444fbc747b0291ace627b1f2d6ef33`：双向 Mamba 后使用随 marker 数增长的 flatten decoder；源矩阵列序不必等于物理顺序；默认每轮使用测试折选择模型，也提供训练内验证选项。限制已在仓库披露。可继承的是结构实现经验，不能将其默认评估或 decoder 原样迁移到千万 SNP。[BiMSGP 代码](https://github.com/liuxumail-create/BiMSGP/tree/71084c8fa5444fbc747b0291ace627b1f2d6ef33)

GP-WAITER 提供 GWAS 加权、局部压缩与 Transformer 的组合。Methods 同时描述训练子集重算权重和按测试表现保存 checkpoint；权重隔离并不意味着全部选择过程隔离。因此可作为架构参照，数值排名需要统一协议后重估。[GP-WAITER](https://www.nature.com/articles/s41467-026-71035-5)

层次化模型将 SNP 压缩为窗口 token，可以缩短后续传播长度，但 O(M) 复杂度不能回答表征是否仍能识别哪个位点发生何种变化。若只输出 dosage 均值或变异计数，不同单倍型可映射到相同 token。必须比较全 marker 加性模型、同 token 的线性/MLP/CNN 与 SSM，分别检验压缩损失和长程模块收益。

结构消融也需可解释。固定物理窗口之间的中心距离接近常数，删除这项编码可能几乎没有干预；置乱顺序但保留坐标并未删除位置信息；对集合不变 encoder 置乱理论上应无效果。实验前须定义干预对象，不能把任何置乱损失统一称为学到真实基因组结构。

PlantCAD2 等 DNA 基础模型处理连续序列和功能任务，与 accession×SNP dosage 预测不同。它们可以提供 sequence prior，但改变输入与预训练条件；G×E 和多组学同理，应作为独立增量，而非同时并入第一阶段密度问题。[PlantCAD 作者仓库](https://github.com/plantcad/plantcad)

## 5. 贡献与结论边界

可检验的贡献是：在一致样本、来源和外层划分下估计额外常见及低频变异的预测收益；量化结构表征的收益与压缩代价；揭示这些收益对遗传背景外推的依赖。此次检索不足以支持“首次”，创新定位仍须持续追踪。

证据应同时涵盖原尺度误差、PCC、相对训练均值的 Q²、群体分解和计算成本。固定 OOF bootstrap 只给出条件性不确定性，不覆盖整个训练算法的全部泛化方差。无显著差异不是实用等效；必须预设有意义效应及精度标准。

密度饱和、线性基线胜出、顺序无效或跨群体收益消失，均可形成有价值的结果；前提是比较确实不同且估计精度足够。attribution、attention 或 selective state 只能定位模型敏感性，不能替代因果验证。
