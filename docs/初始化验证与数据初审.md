实际执行`uv run pytest -q`：**8 passed**。测试覆盖：测试基因型不改变训练QC；只在测试出现的变异排除；inner-validation才出现的变异不进入inner-fit；分块核与稠密primal解等价；hash子集嵌套与列序无关；样本重排保持split；恒定相关及中心化误差恒等；重复表型拒绝；将某outer-test所有标签增加10000后，该折选参和预测保持不变。
