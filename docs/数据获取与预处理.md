# 数据获取与预处理

本仓库**不含任何原始或处理后的数据文件**。`.gitignore` 已忽略 `data/raw/`、`data/interim/`、`data/processed/`、`runs/*/`、`tmp/`、`reference/BiMSGP/` 及 `*.vcf.gz` 等基因组大文件；入库的只有 `data/manifests/` 下的审计清单、划分表与哈希绑定，以及代码和文档。

重新执行下列流水线得到的产物，必须与 `data/manifests/confirmatory_v1_1/freeze_amendment_manifest.json` 中冻结的 SHA256 一致；不一致即视为数据漂移，须走正式修订，不得静默覆盖。

## 0. 环境依赖

```bash
uv sync --locked --extra dev --extra data   # data extra 提供 h5py
```

- `bcftools`：正式矩阵构建与 VCF 审计必需（构建前用 `--bcftools "$(command -v bcftools)"` 显式传入）。
- `pigz`：VCF 预检的并行解压后端，可选但建议。
- GPU + CUDA：`audit_common_feasibility_gpu.py` 需要。
- 磁盘：原始层约 20G（其中 VCF 约 18G），正式产物约 12G；建议预留 ≥60G。

所有下载经 `scripts/fetch_resource.py` 完成：脚本**拒绝覆盖**已存在的目标/临时/清单文件，并为每份资源记录 URL、时间、字节数与 SHA256 到 `<输出>.manifest.json`。注意其 `--max-bytes` 默认仅 400MB，下载 VCF 时必须调大：

```bash
VCF_URL=https://1001genomes.org/data/GMI-MPI/releases/v3.1/1001genomes_snp-short-indel_only_ACGTN.vcf.gz

uv run python scripts/fetch_resource.py "$VCF_URL" \
  --out data/raw/1001g_v3.1/1001genomes_snp-short-indel_only_ACGTN.vcf.gz \
  --max-bytes 20000000000

uv run python scripts/fetch_resource.py "$VCF_URL.md5" \
  --out data/raw/1001g_v3.1/1001genomes_snp-short-indel_only_ACGTN.vcf.gz.md5

uv run python scripts/fetch_resource.py \
  https://1001genomes.org/json/1135_accessions_table.json \
  --out data/raw/1001g_v3.1/1135_accessions_table.json

uv run python scripts/fetch_resource.py \
  "https://docs.google.com/spreadsheets/d/1_jp6KKfUC0z1WteS9HUIp4f3ssFZlCV3KXPIvrTW0Fk/export?format=csv" \
  --out data/raw/1001g_v3.1/admixture.csv

uv run python scripts/fetch_resource.py \
  https://1001genomes.org/data/GMI-MPI/releases/v3.1/SNP_matrix_imputed_hdf5/1001_SNP_MATRIX.tar.gz \
  --out data/raw/1001g_v3.1/1001_SNP_MATRIX.tar.gz \
  --max-bytes 400000000
```

不稳定网络下可用 `scripts/fetch_ranges.py <url> --out <file> --workers 8` 做 HTTP Range 分块下载（每块独立重试，完成后再拼接并记录总 SHA256）。

## 2. 解压与源文件审计

```bash
# 只解出 *.hdf5 与 README 成员到独立目录
uv run python scripts/extract_snp_archive.py \
  data/raw/1001g_v3.1/1001_SNP_MATRIX.tar.gz \
  --out data/raw/1001g_v3.1/extracted
# 产物： imputed_snps_binary.hdf5（919,098,786 B，
# SHA256 f3713e66f017187fb3d30b8d6b854794393ab259e6b5bae4b18ca2cafcbb1862）
# 与 kinship_ibs_mac5.hdf5

uv run python scripts/inspect_hdf5.py \
  data/raw/1001g_v3.1/extracted/imputed_snps_binary.hdf5 \
  --out data/raw/hdf5_inspect_2026-09-22.json

uv run python scripts/scan_hdf5_binary.py \
  data/raw/1001g_v3.1/extracted/imputed_snps_binary.hdf5 \
  --out data/raw/hdf5_binary_scan_2026-09-22

# VCF 结构审计 + 双等位 SNP 目录（catalog 是后续构建的输入）
uv run python scripts/audit_1001g_vcf.py \
  --vcf data/raw/1001g_v3.1/1001genomes_snp-short-indel_only_ACGTN.vcf.gz \
  --official-md5 data/raw/1001g_v3.1/1001genomes_snp-short-indel_only_ACGTN.vcf.gz.md5 \
  --source-url "$VCF_URL" --download-tool fetch_resource.py \
  --bcftools "$(command -v bcftools)"
# 输出（默认 --out data/manifests）： 1001g_v31_*（含
# 1001g_v31_biallelic_snp_catalog.tsv.gz 与 1001g_v31_snp_catalog_summary.json）

# HDF5↔VCF 位点映射审计（ALT 语义，见 docs/VCF_ALT语义与HDF5映射审计.md）
uv run python scripts/audit_hdf5_vcf_mapping.py \
  --hdf5 data/raw/1001g_v3.1/extracted/imputed_snps_binary.hdf5 \
  --catalog data/manifests/1001g_v31_biallelic_snp_catalog.tsv.gz \
  --out data/manifests
```

## 3. 正式基因型构建（G0 核心，约 12G 产物）

```bash
# 3a. 全量 VCF 预检（FILTER/FORMAT/GT 行为；pigz 后端可选加速）
uv run python scripts/run_formal_vcf_preflight_parallel.py \
  --vcf data/raw/1001g_v3.1/1001genomes_snp-short-indel_only_ACGTN.vcf.gz \
  --source-manifest data/raw/1001g_v3.1/1001genomes_snp-short-indel_only_ACGTN.vcf.gz.manifest.json \
  --bcftools "$(command -v bcftools)" \
  --out data/manifests/formal_vcf_preflight_v1.json --workers 12

# 3b. 构建 int8 ALT-dosage 矩阵（1135 × 10,707,430；{-1,0,2}，-1 缺失）
uv run python scripts/build_formal_genotype_v1.py \
  --vcf data/raw/1001g_v3.1/1001genomes_snp-short-indel_only_ACGTN.vcf.gz \
  --source-manifest data/raw/1001g_v3.1/1001genomes_snp-short-indel_only_ACGTN.vcf.gz.manifest.json \
  --preflight data/manifests/formal_vcf_preflight_v1.json \
  --catalog data/manifests/1001g_v31_biallelic_snp_catalog.tsv.gz \
  --catalog-summary data/manifests/1001g_v31_snp_catalog_summary.json \
  --admixture data/raw/1001g_v3.1/admixture.csv \
  --bcftools "$(command -v bcftools)" \
  --out data/processed/formal_genotype_v1 --workers 5

# 3c. 产物 QC（形状/值域/排序/缺失/与 HDF5 一致性抽查）
uv run python scripts/audit_formal_genotype_v1.py \
  --dataset data/processed/formal_genotype_v1 \
  --vcf data/raw/1001g_v3.1/1001genomes_snp-short-indel_only_ACGTN.vcf.gz \
  --bcftools "$(command -v bcftools)" \
  --hdf5 data/raw/1001g_v3.1/extracted/imputed_snps_binary.hdf5 \
  --prior-spot data/manifests/1001g_v31_concordance_spot_check.json \
  --out data/manifests/formal_genotype_v1_qc.json
```

## 5. 队列、划分、近克隆与密度冻结（G0/G0.1）

```bash
# 5a. 队列成员审计（交叉核对材料表/群体标签/各表型快照/可选 HDF5）
uv run python scripts/audit_cohort.py \
  --panel data/raw/1001g_v3.1/1135_accessions_table.json \
  --admixture data/raw/1001g_v3.1/admixture.csv \
  --snapshots data/raw/arapheno_2026-09-22 data/raw/arapheno_candidates_2026-09-22 \
              data/raw/arapheno_metabolite_2026-09-22 \
  --hdf5 data/raw/1001g_v3.1/extracted/imputed_snps_binary.hdf5 \
  --out data/manifests/cohort_verified_2026-09-22

# 5b. 确认性性状面板（由可行性注册表 + 原始值目录生成）
uv run python scripts/freeze_confirmatory_traits.py \
  --registry data/manifests/arapheno_feasibility_registry_2026-09-22.tsv \
  --raw-values-dir data/raw/arapheno_feasibility_2026-09-22/raw_values \
  --out data/manifests/confirmatory_v1/trait_panel.tsv

# 5c. 近克隆审计：全链筛查 → 精确边精化 → 分块面板
uv run python scripts/audit_nearclone_chain_full.py \
  --hdf5 data/raw/1001g_v3.1/extracted/imputed_snps_binary.hdf5 \
  --samples data/processed/formal_genotype_v1/samples.tsv \
  --blocks data/manifests/confirmatory_v1/nearclone_v1/nearclone_blocks_d001.tsv \
  --block-id 0 --out data/raw/nearclone_chain_full_2026-09-22.json

uv run python scripts/refine_nearclone_exact_edges.py \
  --hdf5 data/raw/1001g_v3.1/extracted/imputed_snps_binary.hdf5 \
  --samples data/processed/formal_genotype_v1/samples.tsv \
  --panel data/manifests/confirmatory_v1/nearclone_v1/nearclone_marker_panel.tsv \
  --out data/manifests/confirmatory_v1/nearclone_exact_refinement

uv run python scripts/freeze_nearclone_blocks.py \
  --hdf5 data/raw/1001g_v3.1/extracted/imputed_snps_binary.hdf5 \
  --samples data/processed/formal_genotype_v1/samples.tsv \
  --out data/manifests/confirmatory_v1/nearclone_v1

# 5d. 冻结划分（blocked/iid/logo，outer × inner，canonical + 两个备选 salt；
#     仅消费 ID/群体标签/精确分块，不接触表型数值）
uv run python scripts/freeze_confirmatory_splits.py \
  --trait-panel data/manifests/confirmatory_v1/trait_panel.tsv \
  --blocks data/manifests/confirmatory_v1/nearclone_exact_refinement/nearclone_blocks_exact_d001.tsv \
  --samples data/processed/formal_genotype_v1/samples.tsv \
  --out data/manifests/confirmatory_v1

# 5e. 哈希嵌套标记排名（canonical/s2/s3 三份，前缀嵌套）
uv run python scripts/freeze_marker_ranks.py \
  --compact data/processed/formal_genotype_v1/variants_compact.npy \
  --out-dir data/processed/formal_genotype_v1/marker_ranks \
  --manifest data/manifests/confirmatory_v1/marker_rank_manifest.json --workers 12

# 5f. GPU 可行性审计（每个冻结训练折的 COMMON 标记数；只读基因型）
uv run python scripts/audit_common_feasibility_gpu.py \
  --genotypes data/processed/formal_genotype_v1/genotypes.npy \
  --samples data/processed/formal_genotype_v1/samples.tsv \
  --trait-panel data/manifests/confirmatory_v1/trait_panel.tsv \
  --splits data/manifests/confirmatory_v1 \
  --out data/manifests/confirmatory_v1_1/common_feasibility.tsv \
  --summary data/manifests/confirmatory_v1_1/common_feasibility_summary.json \
  --device cuda
```
