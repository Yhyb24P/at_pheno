# 数据与运行契约

## 原始证据

`data/raw/` 保存不可手工修改的下载快照，按来源/日期分目录。每份资源记录 URL、时间、字节数、SHA256、版本、许可/使用要求（来自官方说明）和处理状态。原始大文件不入 Git；小型manifest和审计摘要可进入 `data/manifests/`、`docs/`。不得根据表型名字猜测 accession ID 映射。

已下载的官方HDF5是预插补binary格式，当前没有REF/ALT，尚不满足下面的正式ALT输入契约。文件级维度/ID核验不等于训练输入语义已合格；不得填造REF/ALT以绕过校验。

AraPheno 快照工具只下载目录及指定候选；不自动选择正式性状，也不静默汇总重复值。下载失败在manifest留痕并非零退出。

## CPU pilot 输入

一个目录包含以下文件，文件行序就是矩阵轴的唯一依据。

| 文件 | 必需字段/形式 | 规则 |
| --- | --- | --- |
| `genotypes.npy` | 数值二维array，行sample、列variant | ALT dosage硬调用0/1/2；NaN缺失；当前不接受概率dosage或-1。通过mmap读取 |
| `samples.tsv` | `accession_id`, `genetic_group` | canonical字符串且唯一；不得只用可能冲突的生态型简称；group模式要求非空 |
| `variants.tsv` | `chromosome`, `position`, `ref`, `alt` | chromosome=1..5，1-based正整数，REF/ALT各为不同单碱基；四元组唯一；正式输入按物理顺序 |
| `phenotypes.tsv` | `accession_id`, `trait_id`, `value` | 每trait/accession最多一行；空值/NA/NaN视为缺失，拒绝无穷值；重复应回到汇总协议解决 |
| `provenance.json`（正式数据必需，pilot尚未强制） | source与转换信息 | release、组装、输入hash、脚本版本、allele方向、单位、study和汇总规则 |

CLI按ID求交集并审计未匹配表型，不按行号直接拼标签。非目标性状不参与拟合。真实导入器必须检查缺失与倍性后再转换，不能把HDF5的0/1、PLINK编码和ALT dosage混为一谈。

`--splits`可提供冻结TSV：`accession_id, fold`（制表符），恰好覆盖当前trait的全部匹配样本，每个一次，非负fold编号。group模式检查每组不跨外层折；内层重新按剩余组LOGO，需要至少两个训练组。近亲分块内层尚未实现，不能仅输入分块outer manifest就宣称完整近亲隔离。

## 运行产物

每次使用新的 `runs/<run_id>/`，已有目录拒绝覆盖。中断产生的缺失产物不能算完成：以最后写出的 `provenance.json` 为完成记录。

- `audit.json`：样本/位点总量、交集、缺失、未匹配ID、群体分布。
- `config.json`、`splits.tsv`、`inner_splits_*.tsv`：本次全部设置与划分。
- `qc_outer_*.npz`及inner版本：eligible原列索引、训练means/frequencies/call_rates/MAC。
- `selected_outer_*.npz`：当前密度实际输入；inner选择可从对应QC、固定variants、salt与density重建。
- `tuning.json`：每outer/density的候选误差、选定alpha、内层与外层marker数、capped标志。
- `predictions.tsv`：每accession/density一次OOF；含y、prediction、train_mean、fold、alpha。
- `metrics.json`：逐折与pooled的additive/mean指标；`complete_oof=false`不可冒充全体结果。
- `omitted.json`：不可达到的密度等未执行项；同样真实marker集合的重复层级不代表独立比较。
- `provenance.json`：输入和源码SHA256、环境版本、git commit（尚无提交时null）、运行时间、pilot标记。

只有对应索引与原始variants/sample表和输入hash一同保留，压缩索引才可追溯。完成真实版本冻结后补充硬件、BLAS/CUDA、线程数、峰值内存和逐阶段计时，当前CPU pilot不声称做了完整性能benchmark。

## 与正式协议的差距

pilot不处理VCF/HDF5转换、祖源分层、近亲分块、LD、PC-only、RKHS、多核和SSM，也不输出显著性结论。全局hash只有近似染色体比例；inner用最多K的capped策略并留痕。group模式是公开标签的整组留出，不自动发现或修复标签质量。`genetic_group`不能直接拿国家字段冒充。
