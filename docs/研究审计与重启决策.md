# 研究审计与重启决策

日期：2026-09-22。性质：面向项目重启的重点文献与方案审计，不是完整系统综述。原始两份文稿及 README 保存在 `archive/2026-09-22/`，新稿是研究工作稿，尚未注册为最终分析方案。

## 1. 总体判断

课题值得开展，但当前可支持的研究问题是“增加可用变异分辨率，在什么表型与预测场景下改善预测”，而非“用双向 Mamba 实现千万 SNP 即构成创新”。原稿对强基线、嵌套评估、表型交集、相关性不代表因果的认识基本正确，不应整体推翻。需要修改的是证据强度、可识别的比较、统计诊断和实际执行边界。

把课题暂定为：**拟南芥自然群体中标记分辨率与表型预测泛化：密度、低频变异和基因组结构的分解评估**。以预测规律研究为主线；结构模型作为需要通过信息保留与算力验证的扩展。若后续明确以方法论文为主，仍沿用这些评估规则，但须另行完成独立模型贡献和机制对照。

## 3. 文献证据与可信范围

引用键及访问状态见 [文献证据表](文献证据表.md)。这次优先核验与设计决策直接相关的论文和数据源，未逐条复核原稿 34 篇文献的所有数值；未复跑任何外部论文。将“论文报告”“代码可见”“本项目推论”分开，不能把来源作者的生物学解释当成已证明机制。

Gibbs 等已经研究模型排序与性状类别、结构和标记筛选的关系，因此“不同性状不同最优模型”本身不足以构成独立创新。[E1](https://academic.oup.com/genetics/article/229/3/iyaf003/7954791)

Kelly 与 McLaughlin 使用 nested CV，比仅报告测试折最优 epoch 更接近本研究要求；但本项目仍需统一数据、划分和调参预算后才能比较数值。[E2](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0308962)

ionome 研究直接提示 country 内与 country 间预测不是同一任务，支持分场景评估，而不是把所有群体相关信号称为“虚假”。[E3](https://www.nature.com/articles/s41598-024-63855-6)

GP-WAITER 的 Methods 写道：“The model checkpoint with the highest test set performance was retained and saved for evaluation.” 这支持模型选择偏差风险的判断；实际复现仍需核对代码是否将 test 另作验证集，不能凭这一句断言所有实验都不可用。[E4](https://www.nature.com/articles/s41467-026-71035-5)

## 5. 后续阶段与验收

1. 数据可行性：下载明确版本的基因型，核验校验值/样本/坐标/编码；冻结 accession 映射；列每性状交集、研究与环境、重复规则、各群体样本量。没有这张表不能承诺 6–8 个正式性状。
2. 最小实证：优先一个 phenology、一个非 phenology 候选（按数据条件选，不按模型成绩选），完成训练均值、PC-only、additive、sparse 和 RKHS；密度先 10K/50K/250K/ALL，可行时加 1M；记录每次真实位点数。
3. 结构模型可行性：先同 token 的线性/MLP/CNN 对照与稀疏信号模拟，测 tokenizer 信息损失，再评估 SSM；固定预测头维度与染色体边界。
4. 正式扩展：冻结 primary contrasts、trait panel、inner/outer manifests、预算、SESOI 和停止规则后运行；对被用于反复开发的表型/测试集降级为探索性。
