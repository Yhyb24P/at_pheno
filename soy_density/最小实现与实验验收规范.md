# 植物全基因组表型回归：最小实现与实验验收规范

## 科学问题与范围

研究以 BiMSGP 为主要对标方法，采用大豆 SoyBase 全基因组 SNP 和连续表型，评价预测方法的能力，不以复现 BiMSGP 论文原始成绩为目标。三个问题按优先级为：同材料、表型和面板下 BiMSGP 与强加性基准的性能差异；不同模型的 SNP 密度敏感性；预测精度、计算成本和高维表征的可重复不足。当前主性状为 protein，原加性密度分析保留为其中一个组成部分。

全基因组面板的 GBLUP/Ridge 与 BiMSGP 为主要比较对象；GBLUP/Ridge 必须覆盖密度梯度，BiMSGP 密度分析和 DeepGS/DNNGP 为扩展参照，后续自主算法待确定。当前按用户指示仅使用 BiMSGP 已有数据和成绩，不重训、不推理。已有成绩缺少同协议逐材料预测时，核心问题只能作受限的历史比较，不能写成已完成公平直接对标。后续性状从 BiMSGP 的 Hgt、protein、R1、SdWgt、Yield、oil、R8 中按数据合格性选取，不凭预测分数挑选。

直接模型比较须共享材料、表型、SNP 面板及外层训练和测试材料；预处理和模型选择均仅使用训练材料，统一 PCC、MSE、RMSE、MAE，保存逐材料预测并作配对误差比较。原论文汇总分数采用其原有选模协议，只能作为有明确限制的历史参照。架构修改版本必须另行标识，不能用改小 Flatten 头的模型冒充原始 BiMSGP。

标记增加同时改变遗传信息与关系矩阵估计，两者不能通过一条密度曲线作因果分离。嵌套面板、等数量策略比较、覆盖及 LD 描述、关系矩阵诊断共同提供解释依据；相关性只能支持相应解释，不能证明新增 SNP 的直接功能贡献。现有开发材料已参与 fprior 方法开发，本研究十折结果属于开发集内的折外评价；不称为从未使用过的独立验证，也不等同于向遗传结构明显不同的新群体外推。

两套数据均属于芯片标记，不外推到百万级 WGS。第二性状在 protein 主要比较后确定，不能把当前单性状结果表述为跨性状规律。

## 数据与隔离

旧队列历史比较使用本机既有 BiMSGP 的 15,878 × 42,195 矩阵、旧 protein 标签及原十折文件，参数见 [benchmark.json](benchmark.json)。保留原标记列序、scaffold 和数值编码，不将旧编码套作官方 VCF 剂量做 MAF 筛选。每次训练分别估计中心化与可选方差缩放，单态列保留为零贡献；四内折选择正则化，测试折不参与。原随机外折保持不变，因此这项比较不具备官方队列的近重复组外层隔离。

BiMSGP 复用公布的十折指标，不加载 checkpoint，不新增训练或推理。其原测试折 epoch 选择不能由事后汇总修正；同数据和外折并不意味着同选模协议。没有逐材料预测时，不开展或声称已完成逐材料配对误差 bootstrap。旧队列中与官方封存名单重合的材料只在授权的旧队列历史比较中使用旧标签，不读取官方封存标签文件；不能把这一结果称为官方封存验证。

以下密度、LD 与近重复组约束条款继续适用于已完成的官方 VCF 加性密度实验，保持原实验目标、规则和结果不变。其只读输入、样本与位点身份见 [README](README.md)，参数唯一来源为 [config.json](config.json)。旧队列比较与官方 VCF 密度实验分别维护各自配置，不混用材料、表型或 SNP。

材料规模为表型匹配 17,526、开发 14,020、封存 3,506。封存材料的标签暂不读取，封存基因型不参与 LD、QC、填补、中心化、核尺度或选参。通过现有受保护的开发标签读取接口，按许可 ID 和行校验读取标签。输入变更时重新检查受影响的身份和对应关系；既有完整来源检查不无故重做。

十个外折沿用原近重复组约束，每折测试 1,402，训练 12,618。全部策略与密度共享同一外层训练和测试材料。不得沿用 128/512/2048 的小样本训练预算。每个完整外层训练集内另建四个近重复组约束内折，以组规模优先、固定散列裁决同规模顺序、逐组分配到材料数最少的折；不利用表型值进行分组或分折。

## 面板构造与描述

预定母集预算为 2,000、5,000、10,000、20,000、41,346，分别约为 4.8%、12.1%、24.2%、48.4%、100.0%。预算表示选择排序的前缀长度，实际有效 SNP 可能因训练侧 QC 减少；不得隐瞒实际数量或为了凑数使用测试信息。

物理策略按染色体物理区间分箱，箱内固定散列排序，跨箱逐轮取位点。排序只用目录坐标与固定种子。每个前缀与当前训练 QC 掩码求交，剔除后不补选。该策略保证目录中已有标记区域的均匀抽取，不保证芯片未覆盖区域也得到标记。

LD 策略只用当前实际训练材料。训练均值填补与中心化后，计算配置距离内同染色体位点的剂量相关平方，包含跨物理箱边界的局部位点对。以达到阈值的位点对建立局部 LD 邻接关系，逐次选择覆盖最多尚未代表邻位点的 SNP，固定物理顺序裁决同分；选中的代表与其邻位点从未代表集合移除。代表层及其余合格位点层分别沿固定物理顺序排列，未通过 QC 的位点放在末尾。各预算取同一排序的前缀并应用 QC。该操作是可复现的局部 LD 代表性策略，不声称得到全局最优 tag-SNP 集合。

每个实际内层训练集重新估计 QC 与 LD，不能用外层完整训练集的 LD 排序代替内层排序。每个训练环境内的低密度有效集合必须包含于高密度集合；不同训练环境的 LD 面板允许不同。两种策略的最高密度有效集合必须相同。

保存母集索引、SNP ID、染色体、坐标及每折排序。逐染色体报告实际数、占用物理箱数及目录箱数、覆盖跨度、间距中位数与最大间距、面板内高 LD 位点对数；同时报告训练 QC 母集局部相关平方均值、检查位点对数和代表数。局部窗口内的统计不得标作全基因组所有位点对的 LD。

## 模型、数值与选参

实际训练材料内估计检出率、等位基因频率、均值和方差。按配置筛选，剔除无有效变异的位点，训练均值填补缺失，不逐 SNP 方差标准化。验证和测试只应用训练对象。

令中心化训练矩阵为 Z，s = tr(ZZᵀ)/n，K = ZZᵀ/s；交叉核使用同一 s。模型为预测 = 训练表型均值 + K交叉 (K + nρI)⁻¹(训练表型 − 训练均值)。核平均训练对角线为 1，所有密度与策略共用该规则。对应原始 Ridge 惩罚为 nρs，原始与对偶计算不计为独立算法。

双精度预条件共轭梯度求解，并以原方程的相对残差验收。所有候选必须通过，不因数值失败删除困难参数或改换样本；失败明确记录，相关折不得生成完成标记。针对性数值检查包括与直接原始 Ridge 的预测一致性、缺失值处理、跨物理箱 LD 和组内划分约束。

各密度和策略分别以内层 pooled MSE 选 ρ，误差完全相同选较小值。采用同一初始网格；任一流程最优值落在边界时，向该侧扩展共享网格并重新比较，直至最优值进入内部或达到配置的数值边界。达到硬边界仍最优时显式报告，不把搜索充分性默认为已满足。最终使用整个外层训练集重新拟合预处理、面板和模型，产生外折预测。

## 评价与解释

主指标为全部 14,020 个折外预测的 pooled MSE；辅助指标为 PCC、相对于开发集总体均值的标准 R² 和 MAE。不得用十个折指标的简单均值代替 pooled 指标，不将训练均值参照的 Q² 混称为标准 R²。

分别比较每种策略的相邻密度及完整相对最稀疏面板，并在相同预定预算下比较两种策略。配对材料必须完全一致。误差差值定义为候选平方误差减参照平方误差，负值表示改善；报告绝对差、相对 MSE 降幅、逐折方向及区间。不同策略 QC 后数量可能不同，因此“相同预算”不能自动解释为“相同有效数量”。

固定预测按外折分层，以近重复组为单位有放回抽样，保留选中组全部成员，所有流程使用配对组样本。报告 95% 描述性区间及配置的重复数。该区间条件于当前预测，不包含重新训练和选参变异。相邻密度、端点和策略比较均完整披露；不把多项未经校正的描述性区间当成一项预注册的确证检验。未预定实际意义阈值时，不事后套用 fprior 的 2% 条件，也不凭微小差异宣称实际改进。

关系矩阵报告完整训练 K 的 tr(K)²/tr(K²)，描述关系谱的参与比；这不是有效独立 SNP 数的直接估计。在固定训练材料子矩阵上报告相对完整面板的 Frobenius 差异及非对角相关，并明确子矩阵材料数。诊断用于判断预测变化是否伴随关系结构变化，不用于标签驱动的面板选择。

## 计算成本与完成条件

先用第 0 外折测量完整四内折搜索及外层重拟合，记录真实训练和验证规模、墙钟时间、进程峰值内存、GPU 峰值分配、设备、软件版本及数值残差。12,618 材料的单个 float64 方阵约 1.27 GB，仅是一个关系矩阵的存储量，不代表实际峰值内存。实测可行后执行其余折；身份一致的完整单折可复用。

研究完成须同时满足：十折和全部预算、策略均有完整配对预测；QC、LD、填补与核尺度均来自实际训练分区；近重复组无跨训练和测试重叠；封存材料未被使用；每个训练环境内面板嵌套且完整面板两策略一致；所有求解通过残差检查；标签、材料、面板和预测身份可追溯；指标、区间和图表可以从保存预测复算。

交付包括可复用实验入口与单一配置、面板及来源目录、每折预处理和覆盖/LD 统计、折外预测、密度性能曲线、配对误差与区间、关系矩阵诊断、计算成本。尚未完成的折、数值失败和范围限制不得改写为研究结论。新增性状、群体外推或启用最终封存集属于后续研究。
