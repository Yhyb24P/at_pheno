# BiMSGP 原 SoyBase 队列的加性基准比较

使用既有 15,878 个材料、42,195 个原列序 SNP、protein 标签和原十折分配。BiMSGP 未重训、未运行推理，只复用公布的逐折指标。当前官方 VCF 密度实验保持独立。

| 本轮模型 | pooled MSE | RMSE | PCC | MAE |
| --- | ---: | ---: | ---: | ---: |
| GBLUP-centered | 3.909645 | 1.977282 | 0.714716 | 1.509071 |
| Ridge-standardized | 3.896409 | 1.973932 | 0.715862 | 1.506353 |

GBLUP-centered 与 Ridge-standardized 属于同一加性岭回归模型类，区别是训练侧 SNP 方差缩放，不计作两个独立算法。两者均以内层 pooled MSE 选参，测试折不参与选参。

BiMSGP 原成绩按测试折 PCC 选 epoch；本轮加性基准采用训练侧内层选参。数据和外折一致并不消除选模协议差异。历史汇总指标可做逐折描述性对照，不能恢复 pooled PCC、逐材料配对误差或重新构造无测试泄漏的 BiMSGP 结果。

旧队列与官方 VCF 的封存名单有 3,139 个材料 ID 重合。本次按用户指定的完整历史队列使用旧标签，不读取官方封存标签文件；结果不能作为该官方队列的独立封存评价。

完整预测、内外折统计、参数搜索及历史比较见本目录 TSV/JSON 文件。历史模型间精确性差异与成本比较须保留其协议和设备限制。

## 同原外折的历史成绩对照

下表统一使用平均逐折 PCC；历史 pooled MSE 根据每折人数和已发布 RMSE 重构，因 RMSE 经过舍入而为近似值，不能当作逐材料预测复算值。

| 方法与来源 | 平均逐折 PCC | pooled MSE |
| --- | ---: | ---: |
| BiMSGP，已有成绩 | 0.717101 | 约 4.052653 |
| GBLUP，已有成绩 | 0.718247 | 约 3.871996 |
| GBLUP-centered，本轮 | 0.715157 | 3.909645 |
| Ridge-standardized，本轮 | 0.716302 | 3.896409 |

相对已有 BiMSGP，GBLUP-centered 的 pooled MSE 降低 3.53%，Ridge-standardized 降低 3.86%，两者均为 8/10 个外折的 MSE 较低；平均逐折 PCC 分别低约 0.00194、0.00080。这表明相关性与绝对预测误差给出不同排序，不支持简单宣称某方法全面胜出。已有 GBLUP 的 MSE 还低于本轮两个流程，差异分别约 0.97%、0.63%；本轮不是对原 GBLUP 实现及超参数定义的逐项复现。

BiMSGP 的模型选择指标为测试 PCC，本轮加性选参指标为内层 MSE。指标和选模协议均不同，不能将上述 MSE 差异全部归因于架构。本轮不实施显著性检验，也不将折指标配对冒充逐材料误差配对。

## 计算成本与完成核对

十折计算时长合计约 63.54 分钟，主机进程峰值 RSS 约 10.85 GiB，GPU 峰值分配约 2.18 GiB；不含历史 BiMSGP 训练成本。全部流程最终选择 ρ=10⁻⁴，均位于搜索网格内部。31,756 行预测覆盖两个编码各 15,878 个材料，原十折分配保持不变；pooled 指标复算通过，最大外层求解相对残差为 9.993984599381679×10⁻¹⁰。四项针对性数值检查通过。

结论限定为完整旧 SoyBase 面板和原随机十折下的 protein 历史成绩比较，不等同于近重复组隔离评价、独立封存验证或统一无测试泄漏协议的 BiMSGP 对标。此前 41,346 核 SNP 的密度结果继续独立解释，不能直接代替此旧队列中的密度曲线。
