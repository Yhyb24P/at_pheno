# SoySNP50K 密度与 protein 折外预测结果

完整开发集十折实验于 2026-10-14 13:24 完成。分析使用 14,020 个开发材料，外层每折训练 12,618、测试 1,402，四折内层选择正则化参数；近重复材料组不跨训练与测试。3,506 个封存材料未进入模型或 LD 计算，封存表型未读取。模型为加性 Ridge/GBLUP，没有使用神经网络。设计与方法见 [实验规范](../最小实现与实验验收规范.md)，参数及输入身份见 [identity.json](identity.json)。

## 密度与预测误差

两种选择策略从 2,000 增加到 20,000 SNP 时，每个相邻密度比较均在十个外折中降低 MSE。完整芯片相对 2,000 SNP 的 pooled MSE 降幅，物理策略为 15.16%，LD 策略为 14.65%。增加标记的收益并不在全部密度、全部策略下保持同一规律：物理策略在 20,000 后继续改善，LD 策略在 20,000 时得到最低观测 MSE，完整芯片略高。

| 预定 SNP 预算 | 物理策略 pooled MSE | LD 策略 pooled MSE |
| --- | ---: | ---: |
| 2,000 | 4.594513 | 4.567074 |
| 5,000 | 4.212375 | 4.158120 |
| 10,000 | 4.073353 | 3.966745 |
| 20,000 | 3.945772 | 3.883012 |
| 41,346 | 3.898160 | 3.898160 |

MSE 单位为蛋白百分比数值的平方。完整面板的 pooled PCC 为 0.708616、R² 为 0.502093、MAE 为 1.519023；LD 20,000 面板相应为 0.709956、0.504028、1.516852。完整精度和全部辅助指标见 [metrics.tsv](metrics.tsv)，曲线见 [PNG](density_performance.png) / [PDF](density_performance.pdf)。

## 配对比较与区间

以下相对降幅以参照 MSE 为分母，正值表示候选改善。区间为 2,000 次固定预测、外折分层、整组配对 bootstrap 的 95% 描述性区间，不包含重新训练和选参的变异，也未作多重比较校正。

| 参照 → 候选 | 相对 MSE 降幅 | 95% 区间 | 改善外折数 |
| --- | ---: | ---: | ---: |
| 物理 2,000 → 完整芯片 | 15.16% | 13.57% 至 16.91% | 10/10 |
| LD 2,000 → 完整芯片 | 14.65% | 13.05% 至 16.54% | 10/10 |
| 物理 20,000 → 完整芯片 | 1.21% | 0.73% 至 1.66% | 10/10 |
| LD 20,000 → 完整芯片 | −0.39% | −0.79% 至 0.02% | 3/10 |
| 物理 10,000 → LD 10,000 | 2.62% | 1.83% 至 3.55% | 10/10 |
| 物理 20,000 → LD 20,000 | 1.59% | 1.06% 至 2.11% | 10/10 |

LD 20,000 的观测误差低于完整芯片，但最后一步差异的区间包含零，不能认定增加到完整芯片必然使预测变差。现有证据支持该策略在约 20,000 SNP 后的增益趋于有限；仅有五个密度点，不能精确确定最优预算。相邻密度和全部策略比较均保存在 [comparisons.json](comparisons.json)，没有仅挑选有利比较。

## LD、覆盖与关系矩阵

外层训练 QC 后，完整有效目录为 41,325–41,334 个 SNP。物理策略的有效数量分别为 1,998–1,999、4,996–4,997、9,993–9,995、19,988–19,993；LD 策略四个低密度均达到预定预算。因此策略比较严格对应相同预定预算，实际数量并非完全相同。

在 1 Mb 局部距离、剂量相关平方不低于 0.8 的定义下，外层 LD 代表集合为 25,031–25,230 个 SNP。LD 20,000 面板在所检查的局部位点对中没有达到该阈值的位点对；物理 20,000 面板有 20,669–21,121 对，完整面板有 64,439–66,675 对。这说明本次选择策略确实改变了局部冗余，但阈值以下的相关和远距离 LD 仍可能存在，代表数不等于有效独立信息量。

物理策略覆盖芯片目录的全部 957 个 1 Mb 物理箱；LD 20,000 面板覆盖 952–954 个箱。LD 策略降低高 LD 冗余的同时，覆盖也有所变化，不能将两种策略的差异全部归因于 LD。

固定 512 个外层训练材料子矩阵上，相对完整面板的非对角相关，十折均值在物理策略 2,000、10,000、20,000 时分别为 0.9478、0.9614、0.9875；LD 策略分别为 0.9566、0.9834、0.9857。关系矩阵接近完整面板与预测精度并非一一对应：LD 20,000 的关系矩阵与完整面板仍有差别，但得到略低的 pooled MSE。这些是描述性诊断，不能据此定量分离新增遗传信息与关系矩阵估计变化的因果贡献。逐折原始诊断及覆盖统计保存在各 `fold_*/` 目录。

## 成本与结果核对

第 0 外折完整耗时约 12.36 分钟。十折计算时长合计约 120.89 分钟，包含各折正则化网格扩展后的重算；其余折约 12.00–12.40 分钟。峰值主机进程 RSS 为 14.27 GiB，峰值 CUDA 分配为 3.70 GiB，GPU 为 RTX 3090；CUDA 数值不含驱动、其他进程和 PyTorch 分配器缓存。成本原值见 [costs.json](costs.json)，版本见 [environment.json](environment.json)。开发基因型一次载入内存供各折复用。

每个外折的共享网格由初始下界 10⁻⁴ 扩展到 10⁻⁵，最终选择均处于网格内部。两个策略的 2,000 预算均选择 ρ=10⁻³，其余预算均选择 ρ=10⁻⁴。最高密度两策略共用同一拟合，预测逐材料完全一致；没有计作两个独立算法。

输出核对覆盖 140,200 行预测，对应十个策略与密度流程各 14,020 个材料；近重复组隔离、面板嵌套和完整面板一致性通过，pooled MSE 与 PCC 已由保存预测复算。最终外层求解最大相对残差为 9.994238227335853×10⁻¹⁰，低于 10⁻⁸ 要求。三个针对性数值检查通过，包含与直接原始 Ridge 求解一致性、训练侧缺失处理、跨箱 LD 和组约束划分。

## 结论范围

本轮结果支持：在该大豆 protein 队列和加性模型下，从稀疏芯片标记增加到约 20,000 SNP 可以稳定改善折外预测；之后的收益受到选择策略影响，完整芯片并不总得到最低观测误差。标记数量之外，局部 LD 冗余、覆盖及关系矩阵变化都需要同时描述。

结果来自单性状、一个固定物理排序种子、一种 LD 规则和同一开发队列。没有检验面板随机种子变化、LD 阈值敏感性、第二性状或遗传结构不同的新群体。该队列此前参与 fprior 方法开发，本轮属于开发集内评价，不能称为从未使用过的独立验证。结论只适用于 SoySNP50K 母集内密度变化，不外推至完整 WGS。
